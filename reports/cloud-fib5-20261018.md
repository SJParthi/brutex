# FIB-5 cloud build report — branch `cloud/fib5-20261018`

FIB-5 is the Fib Flag Breakout engine's walker: one pure state machine that
walks a plan's slots over a stock-day at stage A (Zerodha 1-minute bars) and
at DEEP (GDFL 1-second bars, worst-price fills), with a generated, versioned
exit set and the record codecs. Everything here is in `crates/runner`, which
does no I/O; every fixture is synthetic. Equities stay labelled research,
gross of every charge until FIB-11 (CLAUDE.md section 1).

Done so far: the walker, the event walk, the codec, 83 integration tests and
8 unit tests, the bench rows measured on this host, the docs (D-6380 to D-6390,
FIB5-01 to FIB5-42, L-FIB5-01 to L-FIB5-16 and the C-F5 rows), coverage of
every line, `cargo fmt`, workspace `cargo clippy` and `cargo deny` green, and
the CI source gates that are mine green. Still running: the mutants, the
workspace test and branch coverage.

17 and 22, and the walker's own scan `fib::walk::tests::the_walker_files_do_no_io_and_print_nothing`);

no depth or k parameter; no float (R is an exact rational, `RMultiple`).

## NOT DONE, and why

- **The worse-of-both cross-feed reading** is refused by name
  (`cross_feed_not_built`): it must call PREC-15's `runner::cross_feed`, which
  does not exist (L-FIB5-05).
- **FM-F030's binary search on a volume prefix** for a spill was not built;
  spills step second by second, so no binary search enters the walker
  (L-FIB5-03).
- **Every real-data proof** (below): the walker needs one stock-day's input,
  Zerodha 1-minute bars, GDFL 1-second bars, halt ranges, trail candles and the
  own-past longest gap, and the reader that assembles it is FIB-8's. In this
  tree `cli fib day-check` refuses "not built yet: it arrives with FIB-8", and
  the GDFL store holds raw ticks, not second bars. No command exists that would
  run these proofs, and none is invented here.
