01 Provenance, stated before anything is drawn

This is not the original approved mockup. No mockup file exists anywhere in this repository — every tracked and ignored path was searched. The phrase “the mockup” survives only as prose in eight comments across the two page files, plus the description in commit 6a58d7c. This document is a reconstruction from three sources that do exist: the tokens in theme.css, the markup those pages declare, and those comments. Where the original disagreed with what is drawn here, the original is unrecoverable and this file wins by default — which is exactly the condition that has to end.

That absence is the answer to “why does this area struggle.” Every other claim in this repository is gated: a cost claim faces a bench, an invariant faces a named test, a vendor fact faces a source in the charter. A visual claim has faced nothing, because there has been no artefact to face. “The pages match their designs” has been an assertion in a commit message, and an assertion is not a gate.

Three different absences, three different words no source = this wire never carries it. unknown = the i64::MIN null sentinel arrived. — = not applicable to spot. Collapsing them into one dash is the fallback that hides a failure.
Prices are paisa integers 1,414.05 is 141405 paisa formatted once, at the boundary. A float price anywhere in the browser is a defect, not a rounding choice.
Unsourced columns still hold their width They are not collapsed away — a column that vanishes when empty makes the grid jump between instruments and hides that the field exists at all.

06 The states — the half no mockup has carried

This is the section that answers “why does it look right in the mockup and wrong in the live app.” A mockup is one state with invented data. The running page has at least six, and fidelity work done against the happy path cannot reach any of the others. Each of these is a design deliverable, not an error path.

The rule this section encodes: no two of the six may render identically, and none of them may render as a bare zero. “Nothing here yet”, “this failed”, “you are not entitled” and “still counting” are four different facts, and an operator who cannot tell them apart cannot act on any of them.

07 How this stops being an opinion

This file is only worth the disk it sits on if something checks against it. Three checks make it binding, and all three live in the web-only CI job — the engine still builds with no Node and no web/ present, which CLAUDE.md §2 requires.

Check Fails when Would have caught
token integrity a component reads var(--x) that theme.css never defines, or hardcodes a font stack, colour or radius that a token already names the --raise / --panel2 / --accdeep menus rendering dark on a light page
wire contract a page reads a field the server does not emit, or compares against a value that can never be produced catalogue.feed === feeds.active — every list stuck at “0 shown of 0”
state matrix any region renders identically in two of the six states in section 06 a bare zero standing in for “never pulled”, and a spinner that never resolves
build freshness web/build was not regenerated from the current web/src reviewing one page while running another — the whole class of “it looks different live”
