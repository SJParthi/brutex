The states

Every condition this page can be in, and the sentence it says in each.
Before the work — the ledger cannot take a result

This ledger cannot record a new run

The results file is version 2 and this build writes version 3. A run appended at the wrong stride would corrupt every record after it and still parse, so the engine refuses instead — which is correct, but it refuses after the sweep has run. Run is disabled for that reason. 

mv results.bin results.bin.v2

Nothing is deleted. The runs already recorded stay readable in the moved file.

Running — indeterminate, and saying so
Sweeping. The ladder walks upward until the frequent frontier empties, so how long it takes is decided by the data rather than by a setting — a one-day span finishes in milliseconds and a fine rung over seven years takes minutes per month.

No percentage bar. A sweep is 43 ms to hours depending on the rung, so a percentage would be a guess and a spinner alone says nothing. The elapsed clock is the one honest progress signal.
