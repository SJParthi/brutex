### CI and merge gotchas (read before touching final/all-fixes)
- GitHub silently refuses a CI run if `.github/workflows/ci.yml` exceeds ~520 KB (run "failure", 0 jobs). Keep it
  well under 524,288 bytes; new Gate 11 allowlist reasons go in docs/06-limits.md (D-1451).
- Cloud boxes run as root: 4 store lock/permission tests fail only as root. Run tests as non-root:
  `setpriv --reuid=65534 --regid=65534 --clear-groups`.
- Merging branches conflicts at the tails of append-only docs/04, 05, 06, 11: keep both sides (base first), then
  `cargo check --workspace --all-targets` and `cargo test -p core`. Grep the whole tree for conflict markers.
- Gate 11 runs only after Gate 1e (~70-80 min). Run static gates locally: extract `jobs.language-purity.steps` from
  ci.yml, run with `RUNNER_TEMP=/tmp/claude-0 SOURCE_SCAN=/tmp/claude-0/source-scan` from the repo root; skip 1e.
  Common refusals: `.iter().find/position(`, local `#[allow(` on production lines, `#[path]` test file without
  `#![cfg(test)]` on line 1. Gate 1c/1d: no new lowercase string literal in crates/pull unless declared.
- Gate 14: since D-1601, `source_scan step-runs` refuses a needle line inside if/loop.
- Gate 15 bans the NAME of any other programming language anywhere in tracked text. Write "another language".
- Every push to final/all-fixes restarts the ~6-8 h CI, so batch: one validated push per round, and tell the
  PR #74 CI workstream first.
- `CARGO_BUILD_JOBS=2`, one target dir per worktree. Cloud box: 4 cores / 15 GB, at most 2 cargo jobs at once.
  Full `cargo bench --workspace` OOMs there (fat LTO); Gate 8 in CI is the authority.
- Mutation tests: cargo-mutants 26.2.0. Fast recipe: opt-level 0, incremental,
  `--baseline skip --timeout 900 --in-place --jobs 1 --in-diff x.diff -p <crate>` plus test filters after `--`.
  Read CI shard survivors from `get_job_logs` (artifact download is proxy-blocked).
- `subscribe_pr_activity` on #74 failed for the old account; use scheduled check-ins instead.
- `cargo test -p core` (package `core`, lib `brutex_core`). Never `pkill -f <pattern>` from a command whose own
  text contains the pattern (it kills the shell). In tests, `+` in a query must be sent as `%2B`.
- The audit-run cli test failure (`generated_search_recovers_same_ordinal...`) is not reproducible (green in CI and
